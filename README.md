# NOVAURA MOBILE LAUNCHER

Исходный проект Android-лаунчера на Kotlin и Jetpack Compose.

## Сборка APK

Вкладка **Actions** запускает workflow `Build APK`. После завершения открой успешный запуск и скачай артефакт `novaura-debug-apk`.

> Важно: это Stage 1. Реальный Minecraft runtime пока не подключён, поэтому кнопка запуска показывает соответствующее сообщение. Код ещё нужно проверить сборкой и исправить возможные ошибки компиляции.
